# Assets estáticos

## Avatar do Prism

Coloque aqui o arquivo **`prism.png`** (o fractal etéreo roxo/azul).

- Caminho final: `frontend/public/prism.png`
- O `PrismAvatar` carrega `/prism.png` automaticamente em runtime.
  Enquanto o arquivo não existir, o avatar mostra um placeholder neutro
  (círculo roxo com a letra "P") — basta dropar o PNG e fazer reload.
- Tamanho recomendado: 256×256 (ou maior, quadrado, fundo transparente).
